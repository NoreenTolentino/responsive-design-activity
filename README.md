# Clear Bubbles Laundry

A responsive landing page activity for a laundry service business,
designed to show a responsive layout across desktop, tablet, and mobile screens.

## Live Site:
https://noreentolentino.github.io/responsive-design-activity/
 
## Features
- Responsive layout for desktop, tablet, and mobile devices
- Navigation section with smooth scrolling to page sections
- Services overview highlighting core offerings
- Contact form section for customer inquiries

## Technologies Used
- HTML
- CSS
